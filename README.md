💻 Run Reality Engine

Reality Engine currently runs as a desktop experience.

Requirements
🪟 Windows
🐍 Python 3.12+
📷 Webcam
🌐 Internet connection for external services
💻 Computer capable of running the vision and rendering pipeline
Installation
git clone <YOUR_REPOSITORY_URL>
cd Reality-Engine

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt

Configure the required environment variables.

Then launch Reality Painter:

python -m apps.reality_painter.app

Put your hand in front of the camera.

And start creating.

🔑 Configuration

Some functionality uses external services and therefore requires API credentials.

Keep credentials in environment variables.

Never commit API keys to GitHub.

Example:

$env:GITHUB_TOKEN="your_token"
$env:POLY_PIZZA_API_KEY="your_key"
$env:NVIDIA_API_KEY="Your nividia key"
